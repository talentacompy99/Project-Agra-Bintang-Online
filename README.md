## Cara Online Beneran (10 menit, tanpa coding)

### STEP 1: Buat GitHub (2 menit)
1. Buka github.com -> Daftar
2. New Repository -> nama: agra-bintang-online -> Public -> Create
3. Upload semua file dari folder ini (drag & drop)

### STEP 2: Backend Online di Railway (3 menit)
1. Buka railway.app -> Login dengan GitHub
2. New Project -> Deploy from GitHub Repo -> pilih agra-bintang-online
3. Railway otomatis deploy -> tunggu 2 menit -> dapat link: https://agra-bintang-xxxx.up.railway.app
4. Test: buka https://link-anda.up.railway.app/prices -> harus keluar harga JSON

### STEP 3: Frontend Online di Vercel (3 menit)
1. Buka vercel.com -> Login GitHub
2. Add New Project -> Import agra-bintang-online
3. Root Directory: frontend -> Deploy
4. Dapat link: https://agra-bintang.vercel.app -> INI LINK BUAT SHARE KE PETANI!

### STEP 4: Hubungkan (1 menit)
1. Buka frontend/index.html di GitHub -> Edit
2. Cari API_URL dan ganti jadi link Railway kamu
3. Commit -> Vercel otomatis update
